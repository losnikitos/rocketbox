# Writing Documentation

- Keep documentation brief
- Put documentation as a markdown file in `/docs` folder
- Reference it from `AGENTS.md`
- Mention key files
- Files should be mention with absolute paths, example: `[show.html.erb](/app/views/monitors/catalog_manager/show.html.erb#L123)`. This allows user to cmd+click a link to open a file in the IDE.
- Don't quote code: it changes frequently making the documentation obsolete
